## 1. Мульти-каталоги (пункт 3)

### Механизм

- `BACKUP_PATH` теперь может содержать один или несколько путей через `;`
- Пример:
  ```
  BACKUP_PATH=E:\share\backup1;D:\backup2;\\nas\share\backup3
  ```
- Если `;` в значении **есть** — разбиваем на массив
- Если `;` **нет** — ровно одно значение (полная обратная совместимость)
- Никаких новых переменных в `.env` не требуется

### Изменения в `src/BackupMonitor.ps1`

```powershell
# Вместо одного $RootPath — массив
$RootPaths = $RootPathRaw -split ';'
```

1. **Проверка путей** (было: `Test-Path $RootPath`) — цикл по каждому пути
2. **Сбор файлов** (было: 3 вызова `Get-FileInfo` для одного пути) — общий `Get-ChildItem -Recurse` по всем путям
3. **Исключение папок** — работает для каждого файла независимо от пути
4. **Агрегация** — единый массив `$AllFiles`
5. **CSV + trigger-файлы** — единые для всех путей

### `.env.example`

```
BACKUP_PATH=E:\share\backup
```

Комментарий: можно указать несколько путей через `;`.

## 2. Full-отчёт (пункт 4)

### Поведение

- CSV-файл `Full_yyyyMMdd_HHmmss.csv` со **всеми** файлами
- Фильтр: **никакой** — ни по паттерну имени, ни по возрасту
- Trigger-файл: **НЕ создаётся**
- Инциденты: **НЕ влияет** (не добавляется в `$HasIncidents`)
- Всегда включён, без переменных `.env`

---

## 3. Оптимизация: единое сканирование (стратегия)

### Текущий подход (4 сканирования)

```
Get-ChildItem → фильтр "Daily"    → Daily отчёт
Get-ChildItem → фильтр "Weekly"   → Weekly отчёт
Get-ChildItem → фильтр "Monthly"  → Monthly отчёт
Get-ChildItem → без фильтра       → Full отчёт
```

### Новый подход (1 сканирование → фильтрация в памяти)

```
Get-ChildItem (по всем BACKUP_PATH) → $AllFilesRaw
                                     ↓
  Full:     $AllFilesRaw                                → Full.csv
  Daily:    $AllFilesRaw | Where { путь содержит "Daily"   и возраст > N } → Daily.csv + trigger
  Weekly:   $AllFilesRaw | Where { путь содержит "Weekly"  и возраст > M } → Weekly.csv + trigger
  Monthly:  $AllFilesRaw | Where { путь содержит "Monthly" и возраст > K } → Monthly.csv + trigger
```

- 1 полный обход файловой системы вместо 4
- Метаданные ~50–100 байт на файл → 10 МБ на 100k файлов
- Полностью в памяти, без дисковых операций между фильтрами
